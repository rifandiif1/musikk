# Changelog v9.3

- Android native picker mendukung multi-select file audio.
- Playlist lokal diputar oleh Media3 ExoPlayer dalam MediaSessionService.
- Metadata sesi diperbarui saat lagu berganti; notification/system media controls dapat memakai next/previous berdasarkan playlist.
- Tambah pengujian source untuk native queue, multi-select, dan cache v30.
- Tegaskan batasan: YouTube IFrame tetap tidak dijamin berjalan di background; pemutar native hanya dapat mengelola file lokal atau URL audio langsung yang diizinkan.
- Build Gradle/APK dan pengujian perangkat belum diverifikasi.
